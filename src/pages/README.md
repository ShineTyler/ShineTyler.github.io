# Legacy page templates — not part of the build

The HTML files in this folder are leftover reference templates from an
earlier version of the site. They are **not** used by the build pipeline.

The current generator lives in `src/scripts/sitebuild/` and produces the
complete site (home, about, blog, projects, posts, 404) from
`content/*.md` and `src/data/*.json`. Do not edit these legacy files —
delete them if your tooling allows, or ignore them.
